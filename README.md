# One Line, Big Laugh

A single original joke line, written to `/output/entry.txt` by `main.py`
(Python standard library only). The line takes a therapy-room setup and
turns it on one absurdly specific word — the kind of line you repeat to a
friend the same day.

Run it with `MAKEFUN_OUTPUT_DIR` pointing at your output folder, or let it
default to `/output`.
